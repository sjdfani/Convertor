# Convertor

A simple desktop file converter built with Python and PyQt5. It has a frameless, draggable window with a sidebar for switching between converters and a settings page.

> **Status:** work in progress. More converters and features will be added.

## Features

- **MP4 → MP3**: extract the audio track from a video (`.mp4`, `.mov`) and save it as `.mp3`. Shows the video's duration, the original file size and the size of the new file.
- **JPG → PNG**: convert a `.jpg` image to `.png`, with a preview of the selected image.
- **PNG → JPG**: convert a `.png` image to `.jpg`, with a preview of the selected image.
- **Multilingual interface**: English, Persian, German and Russian, switchable from the settings page.
- **Settings page** with an info panel and animated language and theme panels.

Conversions run on a background thread, so the window stays responsive while a file is being processed.

## Requirements

- Python 3.9
- The packages listed in [`requrments.txt`](requrments.txt):
  - PyQt5 5.15.4
  - pyqt5-tools 5.15.4.3.2
  - Pillow 8.4.0
  - moviepy 1.0.3

## Installation

```bash
git clone https://github.com/sjdfani/Convertor.git
cd Convertor
python -m venv venv
# Windows
venv\Scripts\activate
# macOS / Linux
source venv/bin/activate
pip install -r requrments.txt
```

## Usage

Run the app from the `Source` directory, since `main.py` imports the generated UI module from there:

```bash
cd Source
python main.py
```

1. Choose a converter from the sidebar.
2. Click **Choose** next to *File address* and select the source file.
3. Click **Choose** next to *Save as* and select the output folder.
4. Edit the output name if needed, then click **Convert**.
5. Click **Clear** to reset the form.

Use the home button to return to the start page and **Setting** to change the language or view app info.

## Project structure

```
Convertor/
├── Source/
│   ├── main.py         # Application logic: window, navigation, converters, translations
│   └── convertor.py    # UI layout generated by pyuic5 from convertor.ui
├── photo/              # App icon and UI images
├── requrments.txt      # Python dependencies
└── README.md
```

`convertor.py` is generated by `pyuic5`. Edit the `.ui` file in Qt Designer and regenerate it instead of editing it by hand.
